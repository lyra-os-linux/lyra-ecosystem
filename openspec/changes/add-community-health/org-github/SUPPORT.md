# Suporte

O Lyra OS é mantido por uma equipe pequena. Estes são os caminhos para pedir
ajuda, do mais rápido ao mais completo.

## 1. Pedir ajuda pelo Vega

No Lyra OS, abra o **Vega → Hardware → Diagnóstico de saúde**, rode o
diagnóstico, abra o relatório e toque em **Pedir ajuda**. O Vega monta um texto
com o resultado dos testes, **sem dados pessoais** (nome do computador,
usuários, endereços e caminhos pessoais são removidos), e abre uma pergunta nas
Discussions ou uma issue já preenchida. No Server, o mesmo existe no `vega`
(terminal) e no painel web.

## 2. Perguntar nas Discussions

Dúvidas de uso, instalação e configuração vão para as
[Discussions (Perguntas e respostas)](https://github.com/lyra-os-linux/lyraos-desktop/discussions/categories/q-a).
Procure antes se alguém já perguntou a mesma coisa.

## 3. Ler a documentação

O [site do Lyra OS](https://lyraos.com.br/docs/) tem o guia de instalação, as
notas de cada versão e a página [Pedir ajuda](https://lyraos.com.br/docs/pedir-ajuda.html),
em português, inglês, espanhol e italiano.

## 4. Reportar um defeito

Se algo está quebrado, abra uma issue no repositório da edição:
[Desktop](https://github.com/lyra-os-linux/lyraos-desktop/issues/new/choose) ou
[Server](https://github.com/lyra-os-linux/lyraos-server/issues/new/choose).
Veja como fazer um bom relato no [guia de contribuição](CONTRIBUTING.md).

**Falhas de segurança não vão em issue pública:** siga a
[política de segurança](SECURITY.md).
