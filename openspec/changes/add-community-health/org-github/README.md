# .github

Arquivos de comunidade da organização **lyra-os-linux**: o GitHub os aplica a
todos os repositórios que não têm os seus (código de conduta, contribuição,
segurança, suporte, modelos de issue e de PR) e mostra o `profile/README.md`
na página da organização. Especificação: `lyra-ecosystem`,
`openspec/changes/add-community-health`.
